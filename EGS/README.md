# NV-2.0 — Epic Games Store Submission Kit

Everything needed to upload NV-2.0 to the Epic Games Store.

## Contents

| Path | What it is |
|---|---|
| `build/` | The game files EGS ships: `nv2_engine.exe` + `EULA.txt` + `README.txt` (keyless — no launcher needed) |
| `build_manifest.json` | Generated by Externum (`tools/egs_manifest.ext`) — every file's name, size, sha256 |
| `BuildConfig.json` | EGS BuildPatchTool build configuration |
| `PRIVACY_POLICY.txt` | Privacy policy (required by EGS review) |
| `STORE_COPY.md` | Store page copy (EN/PL) |
| `../store_assets/` | Capsule images + screenshots (see `../store_assets/README.md`) |

## The Windows build

The `.exe` in `build/` was cross-compiled on Linux:

```bash
# inside NV2_ENGINE/Core (rustup target x86_64-pc-windows-gnu + mingw-w64)
cargo build --release --target x86_64-pc-windows-gnu
```

It is the **first executable** for EGS (keyless). The EGS storefront is the
ownership gate — no license key is needed on EGS. Externum DRM still guards
itch.io / direct builds via `nv2_launcher.ebin`.

> Why not the launcher as first executable? `nv2_launcher.ebin` is a Python
> artifact and EGS cannot guarantee a Python runtime on players' machines.
> If you prefer the DRM gate on EGS too, bundle the launcher with PyInstaller
> (`pyinstaller --onefile nv2_launcher.ebin`) and point `LaunchCommand` at
> the produced `.exe`.

## Building the EGS manifest

```bash
cd ../externum
python3 -m externum run tools/egs_manifest.ext -- ../NV2_ENGINE/EGS/build ../NV2_ENGINE/EGS/build_manifest.json
```

## Uploading with BuildPatchTool

EGS requires chunked build data + a manifest, produced by Epic's
BuildPatchTool (BPT). Steps:

1. Get `BuildPatchTool.exe` from your EGS developer dashboard
   (Epic Games Launcher → your product → Builds → Download BuildPatchTool).
2. Stage the build:
   ```bat
   BuildPatchTool.exe -mode=ChunkData ^
     -AppName=NV20 ^
     -BuildRoot=<abs path to EGS/build> ^
     -CloudDir=<abs path to upload staging dir> ^
     -BuildVersion=1.0.0
   ```
3. Upload the staging dir (`Chunks/` + `.manifest`) through the EGS
   developer portal, or via the UploadBuild BPT mode if configured.

## Entitlements (key-based vs keyless)

- **Keyless (recommended):** EGS issues entitlements to buyers automatically;
  `nv2_engine.exe` runs with no key. Store setup: set your product to
  keyless delivery in the dashboard.
- **Key-based:** generate keys with Externum and upload them to EGS:
  ```bash
  python3 -m externum run tools/keygen.ext -- --secret <DRM-SECRET> \
    --app-id nv2-engine --author "NV-2.0" --count 100
  ```

## Before you submit (checklist)

- [ ] Rebuild `nv2_engine.exe` from the current source (save path fix +
      `--version` flag are included in this build).
- [ ] Sign the build (optional but recommended — EGS can verify).
- [ ] Fill real store copy (see `STORE_COPY.md`) + capsule art (placeholders
      in `../store_assets/` — replace with final art).
- [ ] Privacy policy reviewed (see `PRIVACY_POLICY.txt`).
- [ ] EGS developer verification (tax/payout forms) started — it gates
      everything and takes weeks.
- [ ] Product rating set (PEGI 3 / ESRB E) and age gate configured.
- [ ] Test the `.exe` on a real Windows machine (Vulkan-capable GPU).
