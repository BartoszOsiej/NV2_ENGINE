What it does

A from-scratch game engine — not a framework, not a tutorial.

🧠

MeMLP Neural Terrain

An embedded neural network (ndarray, pure CPU) learns vegetation placement, biome classification and texture styles while you play — trained online in a background thread, checkpointed as ~14 KB JSON.

Machine Learning
🟦

Voxel Engine

Full voxel pipeline: chunk loading, greedy meshing, block interaction, inventory/crafting. GPU-driven rendering with wgpu — no OpenGL, no Vulkan SDK.

wgpu
🌐

Real-Climate Worlds

Every seed maps to a real location on Earth. NASA POWER climatology drives biomes, weather and sky; Open-Meteo feeds the online trainer. Offline fallback keeps worlds fully playable.

NASA POWER
🎮

Gameplay Loop

Menus, save/load, item handling, block placement, world simulation. A complete playable game, not a graphics demo.
