What it does

A from-scratch game engine — not a framework, not a tutorial.

🧠

MLP Neural Renderer

Procedural terrain generated by a trained neural network. No hand-crafted heightmaps — the MLP learns terrain patterns and generates infinite worlds on the GPU.

Machine Learning
🟦

Voxel Engine

Full voxel pipeline: chunk loading, greedy meshing, block interaction, inventory/crafting. GPU-driven rendering with wgpu — no OpenGL, no Vulkan SDK.

wgpu
🌐

Multiplayer TCP

Real-time multiplayer over raw TCP sockets. Player sync, world state replication, entity interpolation. No game server framework — hand-rolled networking.

Networking
🎮

Gameplay Loop

Menus, save/load, item handling, block placement, world simulation. A complete playable game, not a graphics demo.

Game Design
📦

crates.io + GHCR
